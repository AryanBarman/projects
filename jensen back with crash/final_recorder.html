Serve this folder (see README below) and open http://localhost:8765/final_recorder.html in Chrome or Edge on a computer with a GPU. Keep this tab in the foreground while recording.

Cuts: each part ends 0.35 s after its voice-over ends, so there are no frozen tail frames. Transitions: 0.45 s cross-fade between parts of one act; fade to black plus an act title card (2.4 s) between acts. Output is WebM (VP9 + Opus). Join the per-act files with ffmpeg: ffmpeg -f concat -safe 0 -i list.txt -c copy full.webm, where list.txt has one file 'act1.webm' line per file, or re-encode to MP4 with -c:v libx264 -c:a aac.

README: copy the whole projects folder (including audio) to the recording computer, open a terminal in it, run python -m http.server 8765, then open the URL above. The 3D acts (3, 5, 6, 7) load Three.js from unpkg.com, so that computer needs internet.
